## 📌 Overview


OTrack is an OSINT username and account-tracking tool that checks the existence of a given username across a wide range of online platforms. It probes each site's profile endpoint concurrently and reports found accounts with their URLs. It runs as a desktop application for authorized OSINT investigations.

---

## ✨ Features


- Username existence checks across many social and web platforms
- Concurrent probing for fast enumeration
- Clear found/not-found reporting with direct profile URLs
- Configurable timeout and request handling
- Export of discovered accounts for reporting
- Desktop UI in the OWLSec theme with an offline --self-test

---

## ⚙️ Requirements

- **Linux**
- **No Python installation needed** — runs as a standalone executable
